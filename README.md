# Splatter Phoenix website

First-pass Astro website for Splatter Phoenix, an alternative pop punk band from Richmond, Virginia.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The static build is written to `dist/` and is suitable for Cloudflare Pages.
